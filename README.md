📄 Netflix Clone 
The Netflix Clone is a web project that recreates the look and feel of Netflix.

This clone focuses on design, layout, and user interactio.It is intended to show skills in responsive web design, modern UI/UX practices, and basic client-side scripting.

Key Features:
Home page with featured movies/shows banner
Multiple rows of movie thumbnails (like Trending, Top Rated, etc.)
Hover effects on movie posters
Responsive design for mobile, tablet, and desktop
Search bar (optional — can be made functional with JavaScript filtering)
Technologies Used:
HTML5 for structure
CSS3 (and optionally Flexbox/Grid) for styling and layout

Goal:
Improve frontend web development skills
Practice creating a pixel-perfect UI based on a real-world app
Understand responsive design and dynamic page interactions
